# How to write PURL tests
The PURL specification includes a test suite comprised of unit test cases.
There are no system or integration test cases because PURL is a data standard,
not an application or other software system.

See the [PURL test suite](https://www.packageurl.org/docs/purl/test-suite)
documentation for more information about how the test suite is organized.

## Specification- versus type-level test cases
In addition to the internal structure of PURL test cases there are two
test case levels: specification and type.
- Specification-level test case
- Type-level test cases
